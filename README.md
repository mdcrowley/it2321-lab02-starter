# IT-2321 Lab 2: Functions with Conditionals and Loops

**Week 4 | Reading: Eloquent JavaScript, Chapter 3**

This lab is practice with defining functions, passing parameters, returning values, and using conditionals and loops inside them.

## Getting started

1. Rename this repository to `it2321-lab02-lastname` (your last name, all lowercase) and set it to Private.
2. Clone it and open the folder in Visual Studio Code.
3. Open `index.html` in your browser, and open the developer console to see your output.
4. Write your code in `script.js`, replacing each `TODO` with your own work.

## What to do

- Write at least three functions, each one focused on a single job.
- At least one function must use a conditional (if/else or switch).
- At least one function must use a loop (for or while).
- Every function should return a value rather than only printing.
- Test each function with a few inputs and confirm the results.

## Files

- `index.html` — the page that loads your script. You usually do not need to change much here.
- `script.js` — where your work goes.
- `styles.css` — basic styling you may adjust.
